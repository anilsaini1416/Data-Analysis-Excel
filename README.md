# Data-Analysis-Excel

This project involves a comprehensive analysis of mobile sales data using Microsoft Excel. The goal was to transform raw transaction records into an interactive dashboard that helps business owners track performance and understand customer behavior.

<img width="1650" height="783" alt="Screenshot 2026-05-07 090931" src="https://github.com/user-attachments/assets/119b9be1-68ba-4b6b-be4f-d30dc8ec1b02" />

## 🚀 Key Insights

Revenue Tracking: Real-time visibility of Total Revenue (₹40.22M) and Units Sold (50,074).

Demographic Analysis: Insights into sales distribution across different age groups and genders.

Top Performers: Identified the highest-grossing mobile brands and top locations.

Payment Trends: Analysis of customer preferences between Online, Cash, and Credit Card payments.

## ⚙️ Features

Dynamic KPIs: Key metrics that update automatically.

Clean Visuals: Used Bar charts, Pie charts, and Line graphs for easy interpretation.

Data Cleaning: Handled duplicates and formatted raw data for better accuracy.

## 🛠️ Tools Used

Advanced Excel: Pivot Tables, Pivot Charts, Slicers, and Shapes.

Formulas: Utilized TEXT, IF, and advanced cell referencing for dynamic reporting.

## 📂 How to use

Download the .xlsx file from this repository.

Open the file in Microsoft Excel.
